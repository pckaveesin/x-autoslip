```

```

## คำอธิบายสั้น (Short Description)
*จำกัด: ไม่เกิน 80 ตัวอักษร*
```
สแกนสลิปธนาคารอัตโนมัติด้วย AI จัดหมวดหมู่รายรับ-รายจ่าย คุมการเงินง่ายในแอปเดียว
```

## คำอธิบายแบบเต็ม (Full Description)
*จำกัด: ไม่เกิน 4,000 ตัวอักษร*
```
เบื่อไหมกับการต้องมานั่งพิมพ์บันทึกรายรับ-รายจ่ายทีละรายการ?

X-AutoSlip ช่วยให้การบันทึกบัญชีการเงินของคุณเป็นเรื่องง่าย แค่เลือกรูปสลิปโอนเงินจากแกลเลอรี ระบบ AI OCR อัจฉริยะจะสแกนยอดเงิน, ธนาคาร, วันที่-เวลา และจัดหมวดหมู่ค่าใช้จ่ายให้อัตโนมัติทันทีในเสี้ยววินาที!

📸 1. สแกนและอ่านสลิปธนาคารอัตโนมัติ (AI Slip Scanner)
• เลือกภาพสลิปโอนเงินได้สะดวกรวดเร็วผ่าน Android Photo Picker
• ประมวลผลแม่นยำด้วย Google ML Kit On-Device OCR
• ดึงยอดเงิน, สกุลเงิน (บาท, USD, EUR ฯลฯ) และวันที่-เวลาให้อัตโนมัติ (รองรับการแปลง พ.ศ. เป็น ค.ศ.)
• รองรับสลิปทุกธนาคารชั้นนำ: กสิกรไทย (KBank), ไทยพาณิชย์ (SCB), กรุงไทย NEXT, กรุงเทพ, ทีทีบี (TTB), ออมสิน (GSB), พร้อมเพย์ และอื่นๆ

🏷️ 2. จัดหมวดหมู่ค่าใช้จ่ายอัตโนมัติ (Smart Auto-Categorize)
• ไม่ต้องเสียเวลาเลือกหมวดหมู่เอง ระบบตรวจจับชื่อผู้รับและบันทึกช่วยจำอัจฉริยะ:
  - 🍜 อาหารและเครื่องดื่ม: GrabFood, Lineman, 7-Eleven, Cafe Amazon, ร้านอาหาร, ชาบู
  - 🚗 น้ำมันและการเดินทาง: ปั๊ม ปตท., Shell, บางจาก, MRT, BTS, ทางด่วน, Grab
  - 🛍️ ช้อปปิ้ง: Shopee, Lazada, TikTok Shop, Lotus, Big C, CJ Express
  - 💡 บิลและสาธารณูปโภค: ค่าไฟ (กฟน./กฟภ.), ค่าน้ำประปา, AIS, True, อินเทอร์เน็ต
  - 💊 สุขภาพและยา: โรงพยาบาล, คลินิก, ร้านขายยา, Watsons, Boots
  - 🎬 บันเทิงและพักผ่อน: ตั๋วหนัง, Netflix, Spotify, Steam

📊 3. สรุปภาพรวมการเงินรายเดือน (Dashboard & Analytics)
• ดูภาพรวมรายรับรวม, รายจ่ายรวม และยอดเงินคงเหลือสุทธิประจำเดือนได้ทันที
• กราฟสัดส่วนค่าใช้จ่ายแยกตามหมวดหมู่ พร้อมแถบเปอร์เซ็นต์ดูง่าย
• จัดกลุ่มรายการตามวัน (วันนี้, เมื่อวาน, ย้อนหลัง) ค้นหาและตรวจสอบง่าย

✍️ 4. บันทึกรายรับ-รายจ่ายเพิ่มเติมได้ตามใจ
• ดีไซน์ทันสมัย สบายตา ตามมาตรฐาน Material 3
• สลับบันทึกรายรับ (สีเขียว) และรายจ่าย (สีแดง) ได้สะดวกรวดเร็ว
• ปรับแต่งหมวดหมู่, โน้ตบันทึก และเปลี่ยนสกุลเงินได้อิสระ

🔒 5. ปลอดภัยสูงสุด ความเป็นส่วนตัว 100% (Offline & Private)
• ระบบสแกนและประมวลผลสลิปทำงานภายในเครื่องของคุณเท่านั้น (On-Device Processing)
• ข้อมูลการเงินทั้งหมดถูกเก็บไว้ในเครื่องของคุณ ปลอดภัย ไม่ส่งข้อมูลขึ้นเซิร์ฟเวอร์ภายนอก
• ไม่ต้องล็อกอินหรือผูกบัญชีธนาคารใดๆ มั่นใจได้ในความปลอดภัย
```
